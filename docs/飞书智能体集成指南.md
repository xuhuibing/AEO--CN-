# AEO系统 × 飞书智能体 · 集成指南

> 将 AEO 认证稽核系统的数据 API 注册为飞书智能体的自定义工具，实现在对话框中对系统进行查询和修改。

---

## 整体架构

```
你 ←→ 飞书智能体 ←→ 🌐 公网隧道 ←→ AEO 服务器 (本机 localhost:3080)
```

---

## 第一步：启动系统 + 隧道

每次使用时需要同时运行两个命令：

```bash
# 终端 1 - 启动 AEO 服务器（自动生成 API 密钥）
cd /Users/bingxu/aeo-system && ./start.sh

# 终端 2 - 启动公网隧道
./tunnel.sh
```

启动后你会看到类似这样的输出：

```
AEO服务器: http://localhost:3080
API密钥:   aeo_a6c0ee6d3b0d6ec22af7051e    ← 飞书配置要用

隧道地址: https://classifieds-travesti-built-trek.trycloudflare.com   ← 公网URL
```

> ⚠️ **注意**：隧道地址每次重启都会变化。当前有效地址见 `tunnel.sh` 的输出。
> 如果用完关闭隧道，下次需要更新飞书智能体中的 API 地址。

## 第二步：在飞书智能体中配置自定义工具

AEO 系统提供以下工具供智能体调用。每个工具需要配置名称、描述、API 地址和参数。

### 基础配置

所有工具共用以下信息：

| 配置项 | 值 |
|:-----|:---|
| 认证方式 | `API Key` |
| 请求头 | — |
| 查询参数 | `api_key=aeo_a6c0ee6d3b0d6ec22af7051e` |

> 如果飞书智能体支持自定义请求头，也可以设置 `X-API-Key` 请求头。

### 工具清单

---

#### 工具 1：查询公司信息

| 字段 | 内容 |
|:----|:----|
| 名称 | `查询AEO公司信息` |
| 描述 | 获取企业基本信息和进出口数据 |
| 方法 | `GET` |
| URL | `https://{隧道地址}/api/company?api_key=aeo_xxx` |
| 响应示例 | `{"name":"上海XX公司","customsCode":"311XXXXXX",...}` |

---

#### 工具 2：更新公司信息

| 字段 | 内容 |
|:----|:----|
| 名称 | `更新AEO公司信息` |
| 描述 | 修改企业名称、海关编码、联系人、进出口数据等 |
| 方法 | `PUT` |
| URL | `https://{隧道地址}/api/company?api_key=aeo_xxx` |
| 请求头 | `Content-Type: application/json` |
| 请求参数 | `name` 企业名称 / `customsCode` 海关注册编码 / `customsOffice` 主管海关 / `legalPerson` 法定代表人 / `financeContact` 财务联系人 / `customsContact` 关务联系人 / `desc` 公司简介 / `tradeAmount` 进出口额 / `growthRate` 增长率 / `declCount` 报关单数 / `inspectRate` 查验率 |
| 请求示例 | `{"name":"新公司名称","customsOffice":"上海海关"}` |

---

#### 工具 3：查询任务列表

| 字段 | 内容 |
|:----|:----|
| 名称 | `查询AEO任务` |
| 描述 | 获取所有任务，可指定部门和状态过滤 |
| 方法 | `GET` |
| URL | `https://{隧道地址}/api/tasks?api_key=aeo_xxx` |
| 可选参数 | `dept=关务部` 按部门过滤 / `status=执行中` 按状态过滤 / `overdue=true` 仅超期任务 |
| 响应示例 | `[{"id":"TSK-2026-0001","name":"安全培训","dept":"HR","status":"待下发","due":"2026-07-15"}]` |

---

#### 工具 4：创建任务

| 字段 | 内容 |
|:----|:----|
| 名称 | `创建AEO任务` |
| 描述 | 创建新的合规任务，自动生成任务编号 |
| 方法 | `POST` |
| URL | `https://{隧道地址}/api/tasks?api_key=aeo_xxx` |
| 请求头 | `Content-Type: application/json` |
| **必填参数** | `name` 任务名称 / `dept` 执行部门 / `owner` 负责人 / `due` 截止日期(YYYY-MM-DD) |
| 可选参数 | `standard` 关联标准编号(如 IC-01) / `req` 工作要求 / `attachReq` 附件要求 |
| 请求示例 | `{"name":"2026年第三季度场所安全检查","dept":"行政部","owner":"张工","due":"2026-09-30","standard":"TS-01"}` |

---

#### 工具 5：更新任务状态

| 字段 | 内容 |
|:----|:----|
| 名称 | `更新AEO任务状态` |
| 描述 | 将任务流转到下一阶段（执行中/审核中/已完成/已关闭） |
| 方法 | `PUT` |
| URL | `https://{隧道地址}/api/tasks/{taskId}/status?api_key=aeo_xxx` |
| 请求参数 | `taskId` 替换为实际任务编号（如 `TSK-2026-0001`） |
| 请求体 | `{"status":"执行中"}` |
| 可选状态值 | `待下发` / `执行中` / `审核中` / `已完成` / `已关闭` |

---

#### 工具 6：查询任务统计

| 字段 | 内容 |
|:----|:----|
| 名称 | `AEO任务统计` |
| 描述 | 获取各类状态任务的统计数量（总数、待下发、执行中、审核中、已完成、超期） |
| 方法 | `GET` |
| URL | `https://{隧道地址}/api/tasks/stats?api_key=aeo_xxx` |
| 响应示例 | `{"total":7,"pending":3,"executing":2,"review":1,"done":1,"overdue":0}` |

---

#### 工具 7：查询认证标准

| 字段 | 内容 |
|:----|:----|
| 名称 | `查询AEO认证标准` |
| 描述 | 获取全部25条南京海关认证标准和9个部门对应关系 |
| 方法 | `GET` |
| URL | `https://{隧道地址}/api/standards?api_key=aeo_xxx` |
| 响应示例 | `{"standards":[{"id":"IC-01","name":"海关业务培训","dim":"内部控制","dept":"关务部"},...],"departments":["关务部","财务部",...]}` |

---

#### 工具 8：审计日志

| 字段 | 内容 |
|:----|:----|
| 名称 | `查询AEO审计日志` |
| 描述 | 获取系统操作记录 |
| 方法 | `GET` |
| URL | `https://{隧道地址}/api/audit-logs?api_key=aeo_xxx` |
| 可选参数 | `type=task` 按类型过滤(task/assessment/auth/data/general) / `limit=20` 限制条数 |

## 第三步：飞书智能体配置入口

不同飞书版本的操作路径略有不同：

### 飞书智能体后台（推荐）

1. 打开飞书 → 智能体 → 管理后台
2. 找到你的智能体 → 「能力配置」或「插件」
3. 添加「自定义工具」
4. 填写工具的 名称、描述、API 地址
5. 测试工具是否可以正常调用
6. 发布生效

### 飞书开放平台（自建应用）

1. 登录 [open.feishu.cn](https://open.feishu.cn/app)
2. 找到你的应用 → 「机器人」
3. 在「事件与回调」中配置消息接收地址
4. 在「权限管理」中开启机器人权限
5. 发布版本

## 第四步：对话示例

配置完成后，你可以对飞书智能体发送这些话：

```
"帮我查一下目前有哪些超期任务"
"创建一条新任务：行政部赵工负责，9月30日前完成季度场所安全检查"
"把 TSK-2026-0001 的状态更新为执行中"
"查询我们公司的海关注册编码"
"修改公司名称为'上海XX国际贸易有限公司'"
"统计一下各部门任务完成情况"
"AEO 认证标准 IC-03 是哪个部门负责的？"
```

智能体会自动识别意图，调用对应的 API，然后把结果用自然语言回复给你。

## 故障排查

| 问题 | 原因 | 解决 |
|:----|:----|:----|
| 工具调用返回 401 | API Key 不匹配 | 检查 api_key 参数或 X-API-Key 请求头是否正确 |
| 工具调用返回 530 | 隧道已断开 | 重新运行 `./tunnel.sh`，更新飞书配置中的 URL |
| 工具返回空数据 | AEO服务器未启动 | 运行 `./start.sh` |
| 修改后网页上数据没变 | 需要刷新页面 | 按 F5 刷新，前端会从服务器同步数据 |
