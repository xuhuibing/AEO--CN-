# 关务AEO认证稽核系统 · 项目方案

> 基于海关总署令第282号（2026年4月施行）及南京海关AEO认证标准检查表
> 文档版本: v2.3 | 最后更新: 2026-06-02

## 一、项目概述

### 1.1 背景

海关总署令第282号《中华人民共和国海关注册登记和备案企业信用管理办法》于2026年4月1日起施行。企业需要建立一套内部管理系统来满足AEO（Authorized Economic Operator）高级认证的合规要求。

### 1.2 业务目标

搭建一套企业内部使用的**AEO合规管理系统**，实现：

| 目标 | 说明 |
|:----|------|
| **展示海关标准** | 将25条认证标准（按南京海关检查表）分配给9个部门，明确各自的证据要求（制度/记录/审批） |
| **检查标准自查** | 各部门逐项对照25条标准的具体检查要点，标记合规/不合规/不适用，上传自查证据 |
| **分发管理任务** | 创建→执行→上传证据→审核→归档的全流程任务管理，支持批量操作 |
| **演示给海关看** | 一键切换海关演示模式，只读展示所有合规证据 |
| **财务状况管理** | 年度列表视图+季度指标录入、自动评估达标、记录填写人员/日期/负责人 |
| **供应商信用管理** | 维护供应商名单，记录海关资质查询历史与信用等级 |

## 三、系统架构

```
                          ┌──────────────────────────────┐
                          │      浏览器 (前端 SPA)         │
                          │  Tailwind CSS + Chart.js       │
                          │  11个模块 + RBAC登录           │
                          │  localStorage + IndexedDB      │
                          └──────────┬───────────────────┘
                                     │
                          ┌──────────▼───────────────────┐
                          │    REST API 服务层 (12+端点)  │
                          │    Node.js HTTP 原生模块       │
                          │    Basic Auth + API Key 双认证 │
                          └──────────┬───────────────────┘
                                     │
                          ┌──────────▼───────────────────┐
                          │    数据持久化层                 │
                          │  data/*.json (服务端文件)      │
                          │  localStorage (浏览器缓存)     │
                          │  IndexedDB (文件存储)          │
                          └──────────────────────────────┘
```

### 数据流

```
用户操作 → saveData(key, value) → PUT /api/data/:key → data/*.json
                                  ↕
页面加载 ← initFromServer() ← GET /api/data/:key
```

- **前端优先**: 操作先写入localStorage，再异步同步到服务端（fire-and-forget）
- **启动加载**: `initFromServer()` 从服务端读取数据填充localStorage
- **文件独立**: 制度文件/培训资料/审计报告存储在IndexedDB，不上传到服务端

## 五、部署方案

### 5.1 快速启动

```bash
cd /Users/bingxu/aeo-system

# 默认启动（端口3080）
./start.sh

# 自定义端口/密码
./start.sh 8080 admin mypass

# 带飞书集成
./start.sh 3080 aeo aeo2026 "" cli_appid app_secret
```

### 5.2 访问地址

| 位置 | 地址 |
|:----|:-----|
| 本机 | http://localhost:3080 |
| 局域网 | http://192.168.x.x:3080 |

### 5.3 认证方式

- **网页访问**: Basic Auth（用户/密码）
- **API访问**: X-API-Key 请求头 或 ?api_key= 查询参数
- **飞书回调**: API Key认证
