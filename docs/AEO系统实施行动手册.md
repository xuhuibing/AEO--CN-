# AEO系统实施行动手册

> 这是落地实操指南 —— 今天看完，明天就能启动。

---

## 第一步：启动（第1天）

### 1.1 取得老板授权

给老板看一句话：

> 海关282号令4月1日已实施，AEO认证/复核将重点核查**执行是否到位**。  
> 我们需要一个系统来统一管理标准、分派任务、留存证据，否则海关来的时候现场拿不出来。

### 1.2 任命关务负责人

正式发文指定一位高级管理人员（VP/总监级）全面负责AEO合规。

---

## 第二步：搭建系统（第1-2周）

### 推荐路径：钉钉宜搭 / 飞书多维表格 / 简道云

如果不确定选什么，**从飞书多维表格（Bitable）或Excel开始最快**，先跑起来再迭代。

### 最小可行方案（Excel + 共享文件夹）

| 组件 | 存放位置 | 说明 |
|------|---------|------|
| 标准条目库 | Excel | 用上面的《AEO标准条目库与部门任务分配表》 |
| 任务追踪表 | Excel | 列出任务、负责人、截止日、状态 |
| 证据文件夹 | 共享网盘 | 按"标准编号"建子目录，各部门往里丢文件 |
| 演示目录 | 共享网盘 | 按四大维度整理，海关来时直接打开 |

> 注意：如果是Excel方案，需要指定一个人负责更新和维护，避免版本混乱。

---

## 第三步：分发任务（第2-3周）

### 3.1 召开AEO启动会

参会部门：关务、财务、法务、行政、物流仓储、HR、采购、IT、内审  
议程：

1. 海关282号令变化说明（15分钟）——关务部
2. 各部门在AEO中的职责（15分钟）——关务部
3. 系统/工具使用方法（15分钟）——IT/关务部
4. 确认各部门对接人（10分钟）——全员

### 3.2 每个部门指定AEO对接人

每个部门指派1名AEO对接人，负责：
- 执行本部门AEO任务
- 上传证据到系统
- 配合内审和海关检查

### 3.3 分发部门任务清单

给每个部门一份只包含他们自己的任务清单（来自上面的条目库），格式：

```
【行政部 - AEO任务清单】
┌──────────────────────────────────┬─────────┬──────────┬────────┐
│ 任务                            │ 周期    │ 首次截止  │ 状态   │
├──────────────────────────────────┼─────────┼──────────┼────────┤
│ 制定场所安全管理制度             │ 初始化  │ 06/30    │ ⬜待办  │
│ 建立门禁授权管理制度             │ 初始化  │ 06/30    │ ⬜待办  │
│ 每月场所安全检查                 │ 每月    │ 07/05    │ ⬜待办  │
│ 每月监控系统检查                 │ 每月    │ 07/05    │ ⬜待办  │
│ 访客登记制度建立                 │ 初始化  │ 06/30    │ ⬜待办  │
└──────────────────────────────────┴─────────┴──────────┴────────┘
```

## 第四步：执行与留痕（第3-6个月）

### 4.1 月度节奏

```
第1周：各部门完成上月任务证据上传
第2周：关务部复核上月执行情况
第3周：关务部发布本月任务清单
第4周：各部门执行本月任务
```

### 4.2 执行注意事项

- **做了就要留痕**：任何操作都要有记录（签字表格、系统截图、照片）
- **连续是关键**：海关会看是否有断档。一旦断档要写情况说明
- **证据要完整**：制度 + 执行记录 + 审批留痕，三者缺一不可

### 4.3 常见问题

| 问题 | 解决方法 |
|------|---------|
| 部门说"太忙了没空做" | 老板在启动会上明确——AEO是硬性考核项 |
| 上传的证据格式不对 | 统一模板（见附录） |
| 证据找不到 | 系统建好目录结构，按标准编号归档 |
| 忘记做周期性任务 | 系统设置提前7天提醒 |

---

## 第五步：内审验证（第6个月）

### 5.1 实施首次内审

内审部按条目库逐条检查：
- 制度有没有？
- 执行记录有没有？
- 记录连续吗？
- 有异常吗？异常处理了吗？

### 5.2 整改闭环

发现问题 → 开整改通知 → 责任部门整改 → 内审验收 → 关闭

---

## 第六步：海关演示准备（第7-8个月）

### 6.1 模拟演示

关务部牵头，组织一次内部模拟演示：
- 打开系统/演示文件夹
- 按四大维度逐条展示
- 检查证据是否齐全、连续
- 记录缺失项并补缺

### 6.2 演示脚本

```
"海关您好，这是我们公司的AEO合规管理系统。  
系统涵盖了282号令要求的全部四大维度标准……

首先看内部控制——我们有关企沟通记录、单证复核月度台账……  
然后是财务状况——我们的审计报告和财务指标……  
守法规范方面——近一年无处罚记录，合规培训覆盖全员……  
贸易安全——场所、货物、人员、商业伙伴、信息安全五个方面都有制度并持续执行……

所有证据按标准分类，连续可追溯，请查看……"
```

### 6.3 海关演示自检表

```
演示前逐项打勾：
□ 系统能正常打开（不要现场装软件）
□ 网络/投影正常（提前测试）
□ 所有文件能打开（不要出现已损坏的文件）
□ 海关人员看得到时间连续性（1月到6月不间断）
□ 每个标准至少看到：制度+记录+审批
□ 内审报告已准备好
□ 整改闭环记录已准备好
□ 培训记录已准备好
□ 有1-2位对接人在场，能回答问题
```
