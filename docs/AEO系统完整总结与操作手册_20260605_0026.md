## 二、项目概览

### 2.1 项目定位

AEO（Authorized Economic Operator，经认证的经营者）认证稽核系统，面向进出口企业的关务部门和管理层，帮助完成AEO高级认证/认证企业的全流程管理。

**核心目标：** 标准学习 → 合规自评 → 差距分析 → 整改跟踪 → 证据归档 → 海关演示

### 2.2 技术栈

| 层级 | 技术选型 | 规模 |
|------|---------|------|
| 后端 | Node.js 原生 HTTP 模块 | `server.js` 1,103行 |
| 数据库 | SQLite (better-sqlite3) WAL模式 | `lib/db.js` 359行 |
| 前端 | 原生 JS + Tailwind CSS | `lib/app.js` 5,207行 |
| 页面 | 单页应用 | `index.html` 1,662行 |
| 认证 | bcryptjs + uuid Session Token | `lib/auth.js` 193行 |
| 标准数据 | JS 数据结构编码 | `standards-data.js` 2,635行, 136项标准 |
| 飞书集成 | 原生 https | `feishu.js` 463行 |
| 总代码量 | — | **11,622行** |

### 4.3 标准项卡片结构

每条标准展示：编号 → 名称 → 标准要求（常驻显示）→ 负责/支持部门 → 执行频率 → 检查要求（文件/询问/实地/抽查）→ 证据完成状态（三色圆点）

## 五、状态流转

### 任务管理
```
待下发 → 执行中 → 审核中 → 已完成 → 已关闭
```

### 整改跟踪
```
待处理(open) → 处理中(in_progress) → 待验收(pending_accept) → 已闭环(closed)
                                                 ↑ 关务部 + 审计部分别确认
```

### 审批流程
```
待处理(pending) → 已通过(approved) / 已驳回(rejected)
```

### 合规自评
```
填写问卷 → 提交 → 生成评估记录 → 历史存档
```

## 六、后端 API

| 方式 | 头格式 | 说明 |

**业务：** `GET/PUT /api/company` | `GET/POST /api/tasks` | `PUT /api/tasks/:id/status` | `GET /api/tasks/stats` | `GET/PUT /api/assessment` | `GET/PUT /api/finance`

**文件：** `POST /api/files/upload` | `GET /api/files` | `GET /api/files/:id/download` | `DELETE /api/files/:id`

**系统：** `GET /api/health` | `POST /api/backup` | `GET /api/versions/:key` | `POST /api/versions/:id/restore` | `GET /api/activity`

## 七、飞书集成

### 7.1 功能

| 功能 | 说明 |
|------|------|
| 消息接收 | 飞书机器人接收文本消息并回复 |
| 意图解析 | 查询公司/任务/标准/日志；创建任务；更新任务状态 |
| 系统通知推送 | 5类事件自动推送：任务创建、任务状态变更、整改验收、审批流转、自评提交 |
| 配置管理 | 系统设置页可配置 App ID/Secret/Chat ID，支持连接测试 |

### 7.2 配置方式

**方式一：命令行动态配置**
```bash
node server.js 3080 aeo aeo2026 "" <APP_ID> <APP_SECRET>
```

**方式二：系统设置页配置**
登录后 → 系统设置 → 飞书集成配置 → 填写 App ID / App Secret → 测试连接 → 保存

### 7.3 Webhook 回调地址

```
http://<服务器IP>:3080/api/feishu/webhook
```

需要在飞书开放平台配置事件订阅，接收 `im.message.receive_v1` 事件。

## 八、部署运维

### 8.1 环境要求

- Node.js ≥ 18
- 操作系统：Windows / macOS / Linux
- 磁盘：建议 10GB 以上（含文件存储）
- 内存：建议 512MB 以上

### 8.2 启动命令

```bash
# 安装依赖
npm install

# 标准启动（端口3080）
npm start

# 自定义端口
node server.js 8080

# 带 API Key 保护
node server.js 3080 aeo aeo2026 my-api-key
```
