## 1. 系统首页（仪表盘）

### 功能定位
全局数据概览，展示AEO认证进展情况、任务统计、评分趋势。

### 页面布局

| 区域 | 内容 |
|------|------|
| 顶部标题栏 | 系统标题、上次更新日期、评分说明按钮、"导出报告"按钮 |
| 综合合规度卡片 | 加权综合评分（评估×40% + 任务完成率×35% + 审计×25%），可点击"评分说明"调整权重 |
| 维度评分矩阵 | 五大维度（内控/财务/守法/贸易安全/附加标准）各维度达标率卡片 |
| 任务统计 | 待下发/执行中/审核中/已完成/超期 数量卡片 |
| 评估趋势图 | 历史评估得分折线图 |
| 部门快照 | 各部门任务完成统计 |
| 近期活动 | 最新操作日志列表 |
| 超期预警 | 超期未完成的任务/整改列表 |

### 操作说明
- **评分说明**：点击后弹出模态框，可调整评估、任务、审计三项权重（滑块调节）
- **导出报告**（关务经理可用）：生成HTML格式的AEO合规综合报告，可打印/保存
- **维度评分卡片**：点击可跳转到对应维度的评估页面

## 4. 认证标准

### 功能定位
AEO高级认证标准展示与日常管理，是系统的核心模块。支持两种视图切换：按维度查看、按部门查看。

### 两种视图

#### 按维度查看
- 分5大维度：内部控制 / 财务状况 / 守法规范 / 贸易安全 / 附加标准
- 每个维度下按子分类（制度）展开，一张子分类卡片包含完整信息
- 额外展示单项标准（卫生检疫/动植物检疫/食品化妆品/商品检验）

#### 按部门查看
- 按责任部门分组，每个部门下展示完整子分类卡片
- 单项标准归入独立分组

### 子分类卡片内容

| 区域 | 内容 |
|------|------|
| 标题行 | 制度名称、维度、负责部门、子项数量 |
| 状态标签 | 达标/基本达标/不达标/不适用（颜色标记：绿/黄/红/灰） |
| 达标情况勾选 | 四选一：达标/基本达标/不达标/不适用，点击即保存 |
| 操作按钮 | 【编辑】展开内联表单填写部门/负责人/协助人；【上传资料】上传佐证文件 |
| 配置信息 | 已保存的部门/负责人/日期等（蓝色背景条） |
| 制度原文 | 点击"展开查看完整制度原文"可折叠展开海关官方标准全文（按句分段排版） |
| 子项列表 | 各子标准编号、名称、检查要点、样本资料 |

### 操作说明
1. **评估制度达标情况**：直接点击卡片中的达标/基本达标/不达标/不适用单选框
2. **编辑负责信息**：点击【编辑】按钮 → 展开内联表单 → 选择负责部门、填写负责人和协助人 → 点击【保存】→ 自动生成对应任务
3. **上传资料**：点击【上传资料】→ 选择文件 → 填写备注 → 上传
4. **查看制度原文**：点击"展开查看完整制度原文…"链接 → 阅读分段排版的海关官方标准
5. **搜索**：顶部搜索框输入制度名称或部门名称进行筛选
6. **切换维度/部门**：右上角"按维度查看"/"按部门查看"按钮切换
7. **切换认证类型**：左上角"高级认证"/"认证企业"按钮切换

## 6. 企业合规自评

### 功能定位
按年度进行系统地合规自评，逐项评价并生成评估报告。

### 页面布局
- 顶部：评估年度选择、认证类型切换、关务人员/复审人员填写
- 进度统计：5大维度各维度已评数/总数进度条、预估综合得分
- 评估问卷：按维度分组展示子分类制度，每个制度含达标勾选和原文查看
- 底部操作：提交评估、重置评估、打印问卷、历史记录

### 操作说明
1. **选择评估年度**：下拉选择目标年度
2. **选择认证类型**：高级认证/认证企业
3. **逐项评估**：对每个子分类制度点击达标/基本达标/不达标/不适用
4. **查看制度原文**：点击"查看制度原文"展开标准全文参考
5. **提交评估**：点击"提交评估"→ 填写关务人员/复审人员 → 确认提交 → 存入历史记录
6. **打印问卷**：生成HTML格式打印版，含所有维度和评估结果
7. **查看历史**：点击"历史记录"查看历次评估结果，可展开查看各维度详细评分
8. **重置评估**：清空当前所有评估结果重新开始

### 数据流转
- 评估结果存入 `scAssessment` → 同步到仪表盘评分
- 提交后存入 `assessmentHistory` 历史记录表
- 提交时自动生成审计日志

## 11. 任务管理

### 功能定位
任务分发、执行跟踪、审核归档的完整流程管理。提供三种视图。

### 三种视图

#### 看板视图（默认）
- 四列布局：待下发 / 执行中 / 审核中 / 已完成
- 每列显示对应状态的任务卡片
- 卡片信息：任务名称、部门、关联标准编号、截止日期、进度百分比
- 超期任务红色背景、近截止日期黄色背景

#### 项目视图
- 按标准维度分组展示（内控/财务/守法/贸易安全/附加标准 + 单项标准）
- 维度汇总行：各维度达标率
- 逐维度展开子分类制度，每行显示：
  - ✅/⚠️/❌ **达标状态**（颜色标记）
  - **制度名称**
  - **负责部门**（从认证标准配置中读取）
  - **负责人**（已指派/未指派）
  - **关联任务状态**（超期红色标记）
- **关键功能**：直观查看"哪些类别未达标、是哪个部门、哪个负责人"

#### 列表视图
- 传统表格：编号/任务名称/部门/负责人/状态/截止日期/操作
- 支持按部门、按状态筛选
- 支持多选批量操作（批量下发、批量完成）
- 超期行红色标记

### 任务生命周期
```
待下发 → 执行中 → 审核中 → 已完成
                   ↓ (退回)
                 执行中
```

### 创建任务
1. 点击右上角"新建任务"按钮
2. 填写：任务名称、关联标准（按维度分组的选择框）、执行部门（含"其他"自定义输入）、负责人、截止日期、执行要求、附件要求
3. 点击"下发任务"

### 操作说明
- **下发**：待下发 → 执行中
- **提交审核**：执行中 → 审核中
- **审核通过**：审核中 → 已完成
- **退回重做**：审核中 → 执行中
- **详情**：查看任务完整信息
- **时间线**：切换任务按时间线展示

## 20. 整改跟踪

> 关务经理和部门AEO对接人可用

### 功能定位
认证发现问题的整改闭环管理：创建 → 执行 → 验收。

### 整改生命周期
```
open → in_progress → resolved → pending_accept → closed
```

### 操作说明
- **创建整改**：填写问题描述、严重程度（严重/一般/轻微）、责任部门、责任人、截止日期
- **更新进度**：执行整改后更新状态和进展说明
- **上传佐证**：整改完成上传证明材料
- **验收/退回**：验收人审核整改结果，通过或退回重做
- **超期预警**：超期未完成的整改自动标红预警
- **筛选**：按状态、部门、严重程度筛选
- **批量操作**：批量分配整改任务

| customs_viewer（海关查看者） | 最小只读权限 |

### C. 数据存储说明

所有业务数据存储在浏览器 `localStorage` 中（自动同步到服务器 SQLite 数据库），键前缀为 `aeo_`：
- `aeo_scAssessment` — 子分类评估数据（达标/基本达标/不达标/不适用）
- `aeo_scTaskConfig` — 子分类负责部门/负责人/协助人配置
- `aeo_scEvidence` — 子分类证据文件记录
- `aeo_tasks` — 任务数据
- `aeo_assessmentHistory` — 历史评估记录
- 其他数据键见系统设置 → 数据版本
