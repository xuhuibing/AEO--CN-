二、项目概览

2.1 项目定位

AEO（Authorized Economic Operator，经认证的经营者）认证稽核系统，面向进出口企业的关务部门和管理层，帮助完成AEO高级认证/认证企业的全流程管理。

核心流程：标准学习 → 合规自评 → 差距分析 → 整改跟踪 → 证据归档 → 海关演示

四、状态流转

任务管理：    待下发 → 执行中 → 审核中 → 已完成 → 已关闭
整改跟踪：    待处理(open) → 处理中(in_progress) → 待验收(pending_accept) → 已闭环(closed)
                                        ↑ 关务部 + 审计部分别确认
审批流程：    待处理(pending) → 已通过(approved) / 已驳回(rejected)
合规自评：    填写问卷 → 提交 → 生成评估记录 → 历史存档

六、部署运维

6.1 环境要求

  • Node.js ≥ 18
  • 操作系统：Windows / macOS / Linux
  • 磁盘：建议 10GB 以上（含文件存储）
  • 内存：建议 512MB 以上

6.2 启动命令

# 安装依赖
npm install

# 标准启动（端口3080）
npm start

# 自定义端口
node server.js 8080

# 带 API Key 保护
node server.js 3080 aeo aeo2026 my-api-key

八、后续完善方向

优先级：高

  1. 认证标准关联任务自动下发 — 标准项达标后自动创建对应整改任务，关联标准编号与任务编号
  2. 飞书通知增强 — 支持飞书卡片消息（非纯文本）、支持飞书内审批操作

优先级：中

  1. 数据看板完善 — 仪表盘增加更多可视化图表，支持自定义看板布局
  2. 批量操作增强 — 整改项批量分配负责人、任务批量更新状态
  3. 审批流程扩展 — 多级审批链（部门负责人→关务经理→高管）、审批超时自动升级

优先级：低（按需）

  1. 多语言支持 — 英文版界面、海关对接双语展示
  2. LDAP/AD集成 — 对接企业统一认证
  3. 集群部署 — 多节点负载均衡、数据库读写分离
  4. 移动App — 微信小程序或飞书小程序，关键审批/通知移动处理
