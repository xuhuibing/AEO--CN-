## 建议执行顺序

```
紧急优先（第1个月完成）：
  IC-01 关企沟通        → 先发文指定负责人
  IC-02 岗位分工        → 明确各岗位职责
  IC-05 信息系统        → 确保系统准备好了
  TS-P01 员工动态       → 花名册整理
  TS-P04 访客管理       → 访客登记制度
  TS-S02 门禁管理       → 门禁系统检查

持续推进（每月执行）：
  IC-03 单证复核        → 每月复核+记录
  TS-S04 视频监控       → 每月检查
  TS-C01~C04 货物管理   → 每单执行

年度必做（固定时间点）：
  FI-01~03 财务         → 年报后2个月内
  IC-06 内审            → 每年固定月份
  TS-B01~03 商业伙伴    → 年度评估
  LC-04 培训            → 至少2次/年
```
