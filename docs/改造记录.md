# AEO 系统生产环境加固 — 改造记录

> 日期: 2026-06-11 02:17
> 基于系统安全评估和生产上线需求进行的全面改造

## Phase 1: 安全加固（全部完成并验证）

### 1.1 安全响应头
- **文件**: `server.js`
- **改动**: 在所有响应中添加安全头：X-Content-Type-Options, X-Frame-Options, X-XSS-Protection, Referrer-Policy, Permissions-Policy, Strict-Transport-Security, Content-Security-Policy

### 1.2 收紧 CORS
- **文件**: `server.js`
- **改动**: `Access-Control-Allow-Origin: *` → 可配置白名单
- **新增**: 环境变量 `CORS_ORIGINS`（默认 `http://localhost:3080`，设 `*` 恢复原行为）

### 1.3 移除 API Key URL 参数
- **文件**: `server.js`
- **改动**: 删除 `?api_key=` 查询参数认证方式，仅保留 `X-API-Key` Header 方式
- **影响**: 使用 `?api_key=` 的旧客户端需要改用 Header

### 1.4 登录速率限制
- **文件**: `server.js`
- **改动**: 新增 `rateLimit()` 函数，登录接口每 IP 每分钟最多 10 次尝试
- **行为**: 超出返回 429 + Retry-After 头

### 1.5 修复错误信息泄露
- **文件**: `server.js`
- **改动**: 登录/注册/通用错误不再返回 `e.message`，改为通用提示，完整日志保留服务端

### 1.6 移除离线认证绕过（关键安全修复）
- **文件**: `app.js`
- **改动**: 删除服务器不可达时的 `confirm('是否进入离线演示模式？')` 逻辑，改为 Toast 提示
- **影响**: 不再允许无认证情况下以 `customs_officer` 角色进入系统

### 1.7 移除前端硬编码 Basic Auth
- **文件**: `app.js`, `index.html`
- **改动**: 
  - 移除 `getAuthHeaders()` 中的 `btoa('aeo:aeo2026')` 回退
  - 备份和健康检查 API 调用改用 `getAuthHeaders()`
  - 登录页面移除预填密码 `value="admin123"`
  - 登录页面提示改为"请使用管理员账户登录"

### 1.8 文件上传类型校验
- **文件**: `server.js`
- **改动**: 在 multipart 和 Base64 上传路径添加扩展名白名单校验
- **允许类型**: PDF, JPEG/PNG/GIF, XLSX/XLS, DOCX/DOC, ZIP, TXT, CSV

### 1.9 修复 RBAC 绕过
- **文件**: `server.js`
- **改动**: Basic Auth 和 API Key 不再跳过 `checkPermission()` 权限检查，统一受 RBAC 控制

### 1.10 Token 移至内存
- **文件**: `app.js`
- **改动**: `authToken` 不再从 `localStorage` 读取/写入，仅在内存中保留
- **影响**: 页面刷新后需要重新登录（安全增强，不再依赖易受 XSS 攻击的 localStorage）

## Phase 2: 数据可靠性（全部完成并验证）

### 2.1 写入队列 + 重试机制
- **文件**: `app.js`
- **改动**: `saveData()` 改为队列模式：先写 localStorage（即时响应），再串行同步到服务器
- **重试**: 最多 3 次，指数退避（1s, 2s, 4s）

### 2.2 数据版本自动清理
- **文件**: `db.js`
- **改动**: 新增 `cleanupDataVersions()`，每 key 保留最近 100 个版本，超出的自动删除
- **触发**: 每小时自动执行

### 2.3 同步更多 key 到服务器
- **文件**: `app.js`
- **改动**: `initFromServer()` 的 `syncKeys` 数组新增: `scoreWeights`, `supplierAssessments`, `standardChecks`

### 2.4 同步指示器 UI
- **文件**: `index.html`, `app.js`
- **改动**: 顶部导航栏新增 `#syncIndicator` 元素，显示"同步中(N 待处理)" / "刚刚同步" / "N 分钟前同步"

### 2.5 定时自动同步
- **文件**: `app.js`
- **改动**: 新增 `startAutoSync()`，每 5 分钟从服务器拉取数据，每 10 秒更新同步指示器
